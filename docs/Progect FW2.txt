Концепция проекта предполагается следующая: не создавать нечто навороченное, а придерживаться стратегии разработки простого инструмента для запуска простых сайтов, с максимально простым, но эффективным управлением. 

Мы не пытаемся переплюнуть CodeIgniter 4, который поддерживает команда и сообщество, но делаем простой фреймворк, ориентируясь на функционал Codeigniter и его кодовую базу.

Репозиторий проекта CodeIgniter 4: https://github.com/codeigniter4/codeigniter4
Репозиторий фреймворка Rameva: https://gitlab.com/rameva/framework

Структура папок проекта повторяет структуру CodeIgniter 4. В корневой директории расположены следующие основные папки:

app/ — это сердце вашего сайта. Тут хранится весь код вашего приложения (контроллеры, модели, виды).

public/ — это "лицо" вашего сайта. Единственная папка, которая должна быть доступна из интернета. Сюда загружают картинки, стили (CSS) и скрипты (JS). Здесь же лежит главный файл index.php.

system/ — это движок фреймворка. Эту папку нельзя трогать и изменять в ней файлы. При обновлении фреймворка она полностью заменяется.

writable/ — папка для временных файлов. Сюда движок записывает логи (ошибки), кэш, сессии пользователей и загруженные файлы. Папка должна быть открыта для записи.

tests/ — место для хранения тестов. Нужна, если вы проверяете свой код на ошибки автоматически.
